“强制开始委派”会在主会话尚无回复时，把首次纯文本回复改为委派；满足条件的 retry 同样生效。“禁止读取 narrative.md”会移除主代理的草稿读取工具，但不影响委派或发布。

子 Agent 的“强制附加报告”会把本回合已完成的报告传给后续委派；靠后的子 Agent 只有在该报告产生后才能接受委派。

叙事 Agent 的“强制发布”会在 narrative.md 已存在且主代理仅返回文本时自动发布。

流式模式用于保持 RPera 与模型服务之间的长请求连接，降低 Cloudflare 524 超时。Agent 仍会在完成后一次性返回结果，不会逐字显示故事。

尾部续写会在每次模型请求的聊天记录末尾临时追加该 Agent 的 prefills/<Agent 名称>.md 作为 assistant 消息；不会写入 session 消息历史。文件在新回合或 retry 开始时读取并冻结。
